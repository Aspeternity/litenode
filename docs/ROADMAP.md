# 开发路线图

**状态**：`未开始` / `进行中` / `已完成` / `已阻塞`（注明原因）。

**规则**：

- 按编号顺序做，除非用户另有安排。
- 一个任务完成的标准是**验收标准全部通过**。标注 `[VPS]` 的条目需要在测试 VPS 上验证，由用户执行并确认。
- 任务内容与 `DESIGN.md` 冲突时以 `DESIGN.md` 为准，并告诉用户。
- 拆分、合并、新增任务需经用户同意，在这里修改并在 `PROGRESS.md` 中说明。

  - [ ] golden file 测试：IPv4 目标、IPv6 目标、同时有 A / AAAA 的域名目标分别生成正确的 DNAT 规则。

  - [ ] [VPS] 修改域名解析后，5 分钟内规则自动更新。
