# LiteNode

LiteNode 是一个轻量的 VPS 节点部署与管理工具，类似没有 Web 界面的 3x-ui。

- 单个 Go 二进制文件，零依赖，通过数字菜单操作，适合小内存、低配 CPU 的 VPS。
- 功能：Xray 节点和客户端管理、nftables 端口转发、nftables 防火墙、SSH 安全配置、系统优化、备份与更新。
- 支持系统：Debian 11 / 12 / 13，Ubuntu 22.04 / 24.04 及之后的 LTS；架构 amd64、arm64。
